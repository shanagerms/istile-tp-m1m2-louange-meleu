# istile-tp-m1-m2-louange-meleu

# ISTILE Annuaire

**Auteur :** Louange Meleu

Mini-annuaire des étudiants d'ISTILE (niveau L3), réalisé avec HTML, CSS et JavaScript, sans framework.
Une page web responsive présente les étudiants, et un programme JavaScript calcule des statistiques à partir d'un fichier JSON.
Il charge aussi des données depuis une API publique de démonstration (dummyjson.com) avec gestion des erreurs.

## Lancer le programme

    npm start
